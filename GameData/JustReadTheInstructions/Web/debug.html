    Cameras

    Render ms is CPU time on the game's main thread. GPU times come from GPU timestamps, taken only while this page or the in-game overlay is open (DirectX 11 only). When the game is CPU bound they also count time the GPU waited for work, so compare them with Render ms. Values in amber need attention; why is listed under the readouts. Mode is window when the camera also has an in-game window open, stream when it only feeds the web page and recordings.
